# shadowfox-ml-internship
Machine Learning Engineer Internship tasks (ShadowFox)

## Overview

This repository contains the machine learning projects completed as part of the ShadowFox Machine Learning Engineer Internship. It covers regression, classification, and natural language processing through three practical projects.

## Projects

### 1. Boston House Price Prediction

**Category:** Regression

A machine learning project that predicts house prices using property-related features.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib

[View Project](./01-boston-house-price/)

### 2. Loan Approval Prediction

**Category:** Classification

A machine learning project that predicts whether a loan application is likely to be approved or rejected based on applicant information.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Joblib

**Test accuracy:** 80.49%

[View Project](./02-loan-approval/)

### 3. Sentiment Analysis Using DistilBERT

**Category:** Natural Language Processing

A project demonstrating a pretrained DistilBERT model that classifies English text as positive or negative and provides confidence scores.

**Technologies:** Python, Hugging Face Transformers, PyTorch, Google Colab, Jupyter Notebook

**Initial evaluation:** 6 out of 6 manually selected example sentences classified correctly. This small test is for demonstration and does not establish real-world accuracy.

[View Project](./03-language-model/)
