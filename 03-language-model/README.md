# Sentiment Analysis Using DistilBERT

This project demonstrates sentiment analysis using a pretrained DistilBERT model. It classifies English text as positive or negative and provides a confidence score.

## Project File

- `language_model_demo.ipynb` — Contains the code, explanations, model demonstrations, evaluation, results, and discussion of limitations.

## Technologies

- Python
- Google Colab / Jupyter Notebook
- Hugging Face Transformers
- PyTorch

## How to Run

Open `language_model_demo.ipynb` in [Google Colab](https://colab.research.google.com/) and run the cells in order.

## Evaluation Note

The model correctly classified all six manually selected test examples. This is a small demonstration, not a reliable estimate of real-world accuracy.
